# ตรวจบน iPhone จริงก่อนยืนยัน mobile QA

สถานะ: ยังไม่ได้ทดสอบบนเครื่องจริง การผ่าน WebKit จำลองไม่ยืนยันการทำงานของ Safari standalone, การล็อกหน้าจอ หรือ native share sheet

ใช้ “ลองด้วยข้อมูลตัวอย่าง” สำหรับการตรวจเมนู กระดาน และรูปแชร์โดยไม่บันทึกขึ้น DB ส่วนเคสซิงก์ให้ตรวจในช่วงที่ไม่ได้เล่นจริงด้วยเกมทดสอบแยก ไม่ใช้เกมของวันแข่ง

| ขั้นตอน                                                | ผลที่ต้องได้                                                   | ผลบนเครื่องจริง |
| ---------------------------------------------------- | ---------------------------------------------------------- | ------------ |
| เปิดเว็บใน Safari แล้ว Add to Home Screen จากนั้นเปิดไอคอน | หน้าเปิดตรง URL ที่บันทึก เนื้อหาไม่ถูกดัน และแตะเมนูล่างได้ทันที          | ยังไม่ตรวจ     |
| เลื่อนลงท้ายหน้า แล้วสลับทั้ง 5 เมนู                          | เมนูล่างยังแตะได้ เนื้อหาหน้าใหม่เริ่มบนสุด                           | ยังไม่ตรวจ     |
| เปิด popup สกอร์ จากนั้นแตะช่องและปิดคีย์บอร์ด                | ตอนเปิดไม่เลือกเลขเอง ปุ่มบันทึก/ปิดและเมนูไม่ค้างหลังคีย์บอร์ดหาย        | ยังไม่ตรวจ     |
| ในเกมทดสอบ กรอกสกอร์ รอ “บันทึกแล้ว” ล็อกจอหนึ่งนาทีแล้วกลับมา | สกอร์ยังอยู่ และปุ่มดึงข้อมูลล่าสุดรับข้อมูลที่แก้จากอีกเครื่องได้              | ยังไม่ตรวจ     |
| ลากผู้เล่น/บอลด้วยนิ้ว แล้วเลื่อนหน้าโดยแตะพื้นสนาม              | ผู้เล่นตามนิ้ว หน้าไม่เลื่อนตามขณะลาก และเลื่อนหน้าได้เมื่อไม่ได้ลาก marker | ยังไม่ตรวจ     |
| เปิดรูปแชร์ แล้วกดแชร์และยกเลิกใน share sheet              | เห็นไฟล์ PNG ที่ถูกต้อง ยกเลิกแล้วกลับมาใช้งานต่อได้                   | ยังไม่ตรวจ     |

บันทึกรุ่น iPhone, iOS, Safari/standalone, วันเวลาและผลจริงในตารางนี้เมื่อมีการตรวจ อย่าเปลี่ยนเป็น “ผ่าน” จากผลจำลอง
