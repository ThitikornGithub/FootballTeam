# ตรวจบน iPhone จริงก่อนยืนยัน mobile QA

สถานะ: วันที่ 31 ตุลาคม 2026 ผู้ใช้รายงานหลังลองทดสอบว่า “ทุกอย่างก็ดูโอเค” รับเป็นผลตอบรับการใช้งานจากผู้ใช้ ไม่ใช่การทดสอบเครื่องจริงโดย agent รุ่นอุปกรณ์/iOS/โหมด Safari หรือ standalone และผลแยกรายข้อไม่ได้ระบุ

ใช้ “ลองด้วยข้อมูลตัวอย่าง” สำหรับการตรวจเมนู กระดาน และรูปแชร์โดยไม่บันทึกขึ้น DB ส่วนเคสซิงก์ให้ตรวจในช่วงที่ไม่ได้เล่นจริงด้วยเกมทดสอบแยก ไม่ใช้เกมของวันแข่ง

| ขั้นตอน                                                | ผลที่ต้องได้                                                   | ผลรายข้อ         |
| ---------------------------------------------------- | ---------------------------------------------------------- | --------------- |
| เปิดเว็บใน Safari แล้ว Add to Home Screen จากนั้นเปิดไอคอน | หน้าเปิดตรง URL ที่บันทึก เนื้อหาไม่ถูกดัน และแตะเมนูล่างได้ทันที          | ไม่ได้แจ้งแยกรายข้อ |
| เลื่อนลงท้ายหน้า แล้วสลับทั้ง 5 เมนู                          | เมนูล่างยังแตะได้ เนื้อหาหน้าใหม่เริ่มบนสุด                           | ไม่ได้แจ้งแยกรายข้อ |
| เปิด popup สกอร์ จากนั้นแตะช่องและปิดคีย์บอร์ด                | ตอนเปิดไม่เลือกเลขเอง ปุ่มบันทึก/ปิดและเมนูไม่ค้างหลังคีย์บอร์ดหาย        | ไม่ได้แจ้งแยกรายข้อ |
| ในเกมทดสอบ กรอกสกอร์ รอ “บันทึกแล้ว” ล็อกจอหนึ่งนาทีแล้วกลับมา | สกอร์ยังอยู่ และปุ่มดึงข้อมูลล่าสุดรับข้อมูลที่แก้จากอีกเครื่องได้              | ไม่ได้แจ้งแยกรายข้อ |
| ลากผู้เล่น/บอลด้วยนิ้ว แล้วเลื่อนหน้าโดยแตะพื้นสนาม              | ผู้เล่นตามนิ้ว หน้าไม่เลื่อนตามขณะลาก และเลื่อนหน้าได้เมื่อไม่ได้ลาก marker | ไม่ได้แจ้งแยกรายข้อ |
| เปิดรูปแชร์ แล้วกดแชร์และยกเลิกใน share sheet              | เห็นไฟล์ PNG ที่ถูกต้อง ยกเลิกแล้วกลับมาใช้งานต่อได้                   | ไม่ได้แจ้งแยกรายข้อ |

การทดสอบครั้งถัดไปหรือเมื่อพบปัญหาจึงค่อยเก็บรุ่นอุปกรณ์, iOS, Safari/standalone และผลรายข้อ ไม่ถือว่าผลตอบรับภาพรวมหรือ WebKit จำลองยืนยันทุกเครื่อง/ทุกเวอร์ชัน
